## AI transcripts format (place each session under `/ai-transcripts/`)
Filename example: `ai-transcripts/2026-07-31T16-30-00_gpt4o.md`

Metadata header to include at the top of each transcript file:

- Date (ISO): 2026-07-31T16:30:00Z
- Location: (e.g., ChatGPT web, M365 Copilot)
- Model & version: (e.g., gpt-4o-mini)
- Input method: web/UI/API
- Participants: (who in the group used it)

Then include:
- Full prompt(s) (exact text sent)
- Full response(s) (exact full response returned)
- Notes: what you used the response for and which parts were incorporated
